# Стратегия распределения возможностей

Красные зоны на карте требуют сокращения затрат или ошибок. Зелёная зона даёт конкурентное преимущество. Остальные зоны показаны серым. Место выполнения указано для текущего состояния.

| Возможность | Проблема сейчас | Решение | Целевая платформа и причина |
|---|---|---|---|
| Касса, чеки, возвраты | Толстые клиенты и разные версии в магазинах | Buy, SaaS | Cloud POS с офлайн-режимом. Стандартная функция |
| Печать ценников, инкассация | Локальные операции и настройки | Buy, SaaS | Модули Cloud POS. Единые правила и отчёты |
| Лояльность | Тетрадки в купленных магазинах, онлайн-сервис недоступен при обрыве связи | Buy, SaaS | Централизованный сервис лояльности, единый баланс |
| Расчёт премий | Дублирование локальных расчётов и кадрового учёта HQ | In-house, on-premises | Расчёт в существующей SAP ERP без покупки новой системы |
| Приёмка и учёт товаров | Локальные справочники и базы дублируют ERP | Buy + In-house | Приёмка через Cloud POS, мастер-данные и учёт в SAP |
| Финансы, кадры, закупки | Централизованы в HQ | In-house, on-premises | Сохранить SAP. Облачная совместимость текущей версии не подтверждена |
| Промоакции | Риск дублирования правил в локальном ПО | Migrate, PaaS | Перенести Promo Engine в управляемые контейнеры, правила едины |
| Click & Collect | Уникальная логистика и маршрутизация заказов | Build / Migrate, PaaS | Сохранить код Smart Fulfillment, использовать управляемую PostgreSQL |
| Интеграция номенклатуры | 80% позиций проверяют вручную, ошибки сопоставления | Build + Buy, PaaS | Собственный процесс и проверки, готовый ИИ API для поиска кандидатов |
| Поддержка магазинов | Серверы, лицензии, выезды, восстановление дисков | Buy, SaaS | Удалённое управление планшетами и мониторинг |
| Работа с оборудованием | Драйверы встроены в кассу | Buy + In-house, edge | Готовый HAL/Payment Gateway и адаптеры на планшете. USB и фискализация требуют локального доступа |

Целевой стек по классам сервисов: Cloud POS SaaS, Loyalty SaaS, управление устройствами SaaS, управляемые контейнеры, PostgreSQL и очередь сообщений PaaS, объектное хранилище и ИИ API. Поставщик POS должен поддерживать локальную фискализацию и автономную продажу за наличные. Конкретные продукты выбираются после проверки моделей оборудования и договоров.

Новый терминал подключается через адаптер HAL без изменения кассового приложения. Если готового адаптера нет, требуются его разработка и проверка. Универсальная совместимость без этих работ не предполагается.
